# NutriNavigator ML Server

Flask API that recommends foods based on a user's health profile using a trained RandomForest classifier.

## Quick start

```bash
# 1. Create and activate a virtual environment
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

# 2. Install runtime dependencies
pip install -r requirements.txt

# 3. Train the model (generates models/model_pickle)
python train_model.py

# 4. Start the server
python server.py
# → http://127.0.0.1:5000
```

## Training options

```bash
python train_model.py --estimators 200 --test-size 0.20 --seed 0
```

## API

### `GET /health`
Liveness probe.

```json
{ "status": "ok" }
```

### `POST /recommend`

**Body**
```json
{
  "age":      28,
  "height":   1.72,
  "weight":   68,
  "gender":   1,
  "diesease": [1, 7]
}
```

| Field      | Type        | Description                                              |
|------------|-------------|----------------------------------------------------------|
| `age`      | number      | Years (1–120)                                            |
| `height`   | float       | Metres (0.5–3.0)                                         |
| `weight`   | float       | Kilograms (10–300)                                       |
| `gender`   | 0 \| 1      | 0 = female, 1 = male                                     |
| `diesease` | int[]       | Disease codes: 0=none, 1=HBP, 2=LBP, 3=Anaemia, 4=Allergies, 5=Cholesterol, 6=Asthma, 7=Diabetes |

**Response**
```json
{
  "recommended_foods": ["Apple (আপেল)", "Banana (কলা)", "..."]
}
```

## Production deployment

Use `gunicorn` instead of the dev server:

```bash
gunicorn -w 2 -b 0.0.0.0:5000 "server:app"
```

Set `FLASK_ENV=production` (the default) and configure `ALLOWED_ORIGIN` for your frontend domain.
